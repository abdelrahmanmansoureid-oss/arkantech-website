# ArkanTech Website

Professional IT Solutions company website built with **React.js** + **Vite** + **Tailwind CSS**.

## 🌐 Live Demo
Deployed on Vercel — see link in repository description.

## 🚀 Features
- Bilingual Arabic / English with RTL support
- Light modern design with mesh gradients & glassmorphism
- Fully responsive (mobile-first)
- Interactive services bento grid
- WhatsApp-first contact section
- Scroll reveal animations

## 🛠 Tech Stack
- React 18 + Vite 4
- Tailwind CSS 3
- Vanilla CSS animations

## 📦 Run Locally
```bash
npm install
npm run dev
```
